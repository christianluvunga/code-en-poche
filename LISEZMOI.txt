CODE EN POCHE : mise en ligne sur GitHub Pages

1. Sur github.com : "+" en haut à droite > New repository.
   Nom : code-en-poche. Visibilité : Public. Create repository.
2. Sur la page du dépôt : "uploading an existing file".
   Glisse TOUS les fichiers de ce dossier (index.html, sw.js, manifest.webmanifest, les 4 icônes png).
   Ils doivent être à la racine, pas dans un sous-dossier. Puis "Commit changes".
3. Settings > Pages > Build and deployment > Source : "Deploy from a branch".
   Branch : main, dossier : / (root). Save.
4. Attends 1 à 2 minutes. L'adresse sera :
   https://TON-PSEUDO.github.io/code-en-poche/

Installer sur le téléphone (ouvre l'adresse UNE FOIS avec internet) :
- Android (Chrome) : menu ⋮ > "Installer l'application".
- iPhone (Safari) : bouton Partager > "Sur l'écran d'accueil".

Mettre à jour plus tard : remplace index.html sur GitHub, et change CACHE ("code-en-poche-v2") dans sw.js.
Ta progression est enregistrée dans l'appli, sur chaque appareil séparément.
